
# Project: 2026 Vibe Check (Viral IN/OUT Generator)

## 1. Project Overview
We are building a viral, single-page web application called "2026 Vibe Check". 
**Core Functionality:** Users input a specific "Persona" (e.g., "Tired Sysadmin", "Gym Rat", "Academic Weapon"). The app uses AI to generate a humorous, culture-specific list of what is "IN" and what is "OUT" for that persona in 2026. The result is displayed on a stylized card that users can download as an image or share directly to X (Twitter).

**Key Constraints:** - Mobile-first design (most users come from social media).
- Zero friction (no login, no paywall).
- High visual appeal (brutalist or editorial design).

## 2. Tech Stack
- **Framework:** Next.js 14+ (App Router, TypeScript).
- **Styling:** Tailwind CSS.
- **Components:** shadcn/ui (Card, Button, Input, Toast).
- **Icons:** Lucide React.
- **AI Integration:** Gemini Free Tier AI.
- **Image Export:** `html2canvas` (to convert the DOM element to PNG).
- **Validation:** `zod` (to ensure structured JSON output from the AI).

## 3. Design System & Aesthetics
- **Theme:** "Digital Paper" / Editorial look.
- **Background:** Off-white/Cream (`#FDFBF7`) or noise texture.
- **Typography:** - Headings: Serif (e.g., `Playfair Display` or `Merriweather`).
  - Body: Sans-serif or Mono (e.g., `Inter` or `JetBrains Mono`).
- **The Share Card:** - Must look distinct and printable. 
  - Two-column layout: Left (Green/Bold) for IN, Right (Muted/Red) for OUT.
  - Footer with "2026 Vibe Check" branding.

## 4. Data Structure (The API Contract)
The AI must return data in this exact JSON format:
```typescript
interface VibeCheckResult {
  persona: string; // The user's input, capitalized
  ins: string[];   // Array of 5 short, punchy items
  outs: string[];  // Array of 5 short, punchy items
  emoji: string;   // A single emoji representing the vibe
}

```

## 5. Implementation Phases

### Phase 1: Setup & UI (Mock Mode)

* Initialize Next.js app.
* Install shadcn/ui components (`button`, `input`, `card`, `skeleton`).
* Create the `ShareCard` component.
* **Crucial:** Build the UI using *mock data* first. Do not connect the API yet. Ensure the card looks perfect on mobile and desktop.

### Phase 2: The API Route

* Create `/app/api/generate/route.ts`.
* Use OpenAI (`gpt-4o-mini` or `gpt-3.5-turbo`).
* **System Prompt:** > "You are a viral trend forecaster for 2026. The user will provide a specific persona. You must generate a list of 5 things that are 'IN' (trending, cool, healthy, or ironically funny) and 5 things that are 'OUT' (cringe, dated, unhealthy) for that specific persona. The tone should be witty, slightly roasting, and specific to internet culture. Keep items short (under 6 words). Return strict JSON."

### Phase 3: Integration & State

* Create a client-side form.
* Use `useChat` or `useObject` from Vercel AI SDK to stream the response.
* Handle loading states (show a skeleton card while generating).
* Handle error states (e.g., "AI is overwhelmed").

### Phase 4: Sharing & Export

* Implement `html2canvas` function to screenshot the `ShareCard` ref.
* Create a "Download Image" button.
* Create a "Share on X" button that opens a new window with a pre-filled tweet:
> "My 2026 Vibe Check: [Persona]. Generated by [AppURL]"



## 6. Detailed Component Specs

### `ShareCard.tsx`

* **Props:** `data: VibeCheckResult`, `ref: React.RefObject<HTMLDivElement>`
* **Design:**
* Header: "2026 FORECAST"
* Subheader: `{data.persona} {data.emoji}`
* Grid Layout (2 cols):
* Col 1 Header: "IN" (Uppercase, Tracking-widest)
* Col 2 Header: "OUT" (Uppercase, Tracking-widest)


* List items should have comfortable spacing.



### `GeneratorForm.tsx`

* Simple centered layout.
* Input field with placeholder: "e.g. Burnt out Developer"
* Large CTA Button: "Reveal My Fate"

4. Do not use `<img>` tags for icons inside the ShareCard; use SVGs to ensure they render correctly in the screenshot.
